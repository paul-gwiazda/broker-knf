# Broker KNF 0.3

Wersja poprawiająca ergonomię nauki na iPhonie.

## Co poprawiono
- fiszki: najpierw pytanie, po dotknięciu odpowiedź; większa czcionka i pełne wyśrodkowanie,
- blokada przypadkowego powiększania strony przez podwójne stuknięcie,
- po odpowiedzi w quizie odpowiedzi są zwijane do krótkiego podsumowania, dzięki czemu uzasadnienie mieści się wyżej na ekranie,
- ćwiczenie uruchomione z lekcji pokazuje wyłącznie pytania z tego konkretnego bloku,
- tryby Inteligentny / Losowy / Słabe tematy są widoczne tylko w głównym kafelku Trening,
- „Moje błędy” pokazują od razu prawidłową odpowiedź i uzasadnienie,
- powtórka błędu wraca do „Moich błędów”, a nie do strony głównej,
- przycisk Wstecz w treningu zachowuje kontekst wejścia,
- zaktualizowany cache PWA do wersji 0.3.

## Aktualizacja
W repozytorium `broker-knf` zastąp pliki z wersji 0.2 plikami z tego pakietu. Nie zmieniaj ustawień GitHub Pages.

# Broker KNF 0.2
Adaptacyjny trener nauki pod egzamin brokerski.

## Aktualizacja z 0.1
W repozytorium GitHub `broker-knf` zastąp pliki nowymi z tego pakietu, pozostawiając je w katalogu głównym. GitHub Pages opublikuje aktualizację automatycznie.

## Ważne
Postęp jest zapisywany w localStorage przeglądarki/PWA i nie jest usuwany przez zwykłą podmianę plików aplikacji. Nie czyść danych witryny Safari, jeśli chcesz zachować wyniki.

## 0.2 zawiera
- bloki tematyczne i mikrolekcje
- adaptacyjne dobieranie pytań
- profil błędów
- fiszki ze spaced repetition
- dzienny cel, serię i motywatory
- statystyki tematyczne
- tryb egzaminacyjny
- słownik i liczby/terminy
- AI-ready tutor: generuje kontekstowy prompt do ChatGPT bez płatnego API

## Następne paczki merytoryczne
2026 -> 2025 -> 2024/2023 -> starsze archiwum. Pytania prawne wymagają weryfikacji względem aktualnego stanu prawa przed oznaczeniem odpowiedzi jako pewnej.
